VERIFICATION OF THE REPRODUCIBILITY PACKAGE
===========================================

Full re-execution of E1-E7 from this package (python paper_experiments.py all --workers 8)
compared with the raw results of the paper (python verify.py).

1. Geometric, topological and image-processing results (all non-timing columns)
------------------------------------------------------------------------------
Boolean/categorical columns must be identical; numeric columns are compared with a relative
tolerance of 1e-5 (vectorized NumPy reductions may differ in the last bits).

E1: 2520 runs, 27 non-timing columns equal; 9 numeric values differ only by floating-point rounding (max. relative difference 1.2e-06)
E2: 756 runs, 27 non-timing columns equal; 8 numeric values differ only by floating-point rounding (max. relative difference 4.7e-08)
E3: 2100 runs, 1 non-timing columns equal; all values bit-identical
E4: 564 runs, 2 non-timing columns equal; all values bit-identical
E5: 608 runs, 4 non-timing columns equal; all values bit-identical
E6: 1386 runs, 17 non-timing columns equal; 6 numeric values differ only by floating-point rounding (max. relative difference 1.0e-09)
E7: 1000 runs, 7 non-timing columns equal; all values bit-identical

All 8934 runs were reproduced. Only 23 numeric values differ, by floating-point rounding
(maximum relative difference 1.2e-06); every validity flag, safety flag, Ackermann flag and homotopy
class is identical.

2. Computation times (hardware and load dependent)
--------------------------------------------------
The re-execution ran on the same computer as the paper but under a different load; absolute times
were about 4 times larger. The relative conclusions are preserved: paired speed-up of TVE over WDT,
share of queries in which TVE is faster, Friedman ranks, and all length/topology results.
